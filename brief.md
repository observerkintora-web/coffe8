ВАЖНО: я дополнительно загружу тебе изображение нового фона.

Используй ИМЕННО загруженное мной изображение как основной background для всех игровых экранов вместо текущего визуально более блеклого варианта.

Не перерисовывай этот фон через CSS и не пытайся воссоздать его градиентами.

Сохрани само изображение как отдельный asset проекта и используй его через background-image.

Фон должен:
- покрывать весь экран;
- сохранять правильные пропорции;
- работать в PHONE PORTRAIT;
- использовать background-size: cover;
- не растягиваться;
- не деформироваться;
- не становиться блеклым из-за слишком сильного чёрного overlay.

Дополнительные затемнения добавляй ЛОКАЛЬНО там, где нужна читаемость текста, а не одним тяжёлым чёрным слоем поверх всей фотографии.

--------------------------------------------------
ОБЯЗАТЕЛЬНО ВЕРНУТЬ COFFEE BEAN CELEBRATION
--------------------------------------------------

Сейчас эффект дождя/взрыва кофейных зёрен при выпадении приза практически пропал.

ЕГО НУЖНО ВЕРНУТЬ.

Не путай два эффекта:

1. AMBIENT BEANS
Это несколько медленно плавающих зёрен на обычных экранах.

2. CELEBRATION BEAN RAIN
Это отдельная мощная короткая анимация, которая запускается ТОЛЬКО В МОМЕНТ ОТКРЫТИЯ ПРИЗА.

Когда пользователь нажимает:

«Відкрити приз 🎉»

должна происходить последовательность:

закрытая карта
→ вспышка света
→ раскрытие prize
→ усиление rarity glow/rays
→ мощный выброс кофейных зёрен
→ часть зёрен разлетается наружу
→ часть начинает красиво падать сверху вниз
→ постепенно всё затухает
→ остаётся спокойный экран выигранного приза.

Используй существующий:

bean.webp

НЕ генерируй кофейные зёрна CSS-овалами.
Используй реальный прозрачный asset.

--------------------------------------------------
КАК ДОЛЖЕН ВЫГЛЯДЕТЬ ДОЖДЬ
--------------------------------------------------

Хочу заметный cinematic coffee-bean celebration.

Ориентир:

примерно 30–45 зёрен за всю анимацию.

Но НЕ выпускать их все одновременно.

Первая волна:
примерно 15–20 зёрен резко вылетают из области вокруг prize.

Вторая волна:
примерно 10–15 зёрен появляются выше и продолжают падение.

Последние:
несколько отдельных крупных зёрен проходят через foreground.

Продолжительность всего celebration:
примерно 2.0–2.7 секунды.

После этого дождь ПОЛНОСТЬЮ прекращается.

Не делать infinite animation.

--------------------------------------------------
DEPTH / PARALLAX
--------------------------------------------------

Зёрна должны находиться визуально на разной глубине.

BACKGROUND:
маленькие
scale ~0.35–0.6
opacity ~0.35–0.6
небольшой blur
медленнее

MIDGROUND:
scale ~0.65–1.0
резкие
основная масса частиц

FOREGROUND:
scale ~1.1–1.6
несколько крупных зёрен
двигаются быстрее
могут проходить ПЕРЕД prize
небольшой motion/depth blur допустим

У каждого зерна должны немного отличаться:
- X position;
- Y position;
- rotation;
- rotation speed;
- scale;
- velocity;
- gravity;
- opacity;
- delay.

Не должно выглядеть как 30 одинаковых PNG, падающих параллельно.

--------------------------------------------------
СИНХРОНИЗАЦИЯ СО СВЕТОМ
--------------------------------------------------

Самое важное — связать bean animation с reveal.

В момент появления prize:

1. rarity glow быстро усиливается;
2. rays становятся ярче;
3. появляется короткий golden flash;
4. одновременно начинается первый burst кофейных зёрен;
5. prize делает очень мягкий scale:
   примерно 0.88 → 1.04 → 1;
6. затем начинается спокойный floating prize animation.

То есть это должен быть ОДИН celebration moment:

LIGHT + PRIZE + RAYS + COFFEE BEANS

а не несколько несвязанных эффектов.

Для rarity glow использовать:

ЗВИЧАЙНИЙ → emerald green
РІДКІСНИЙ → electric/cobalt blue
ЕПІЧНИЙ → rich violet
ЛЕГЕНДАРНИЙ → premium warm gold

Кофейные зёрна при этом остаются натуральными коричневыми.

--------------------------------------------------
ВАЖНО ПО ПРОИЗВОДИТЕЛЬНОСТИ
--------------------------------------------------

Для большого кратковременного bean celebration используй существующий Canvas-механизм, если он уже есть в проекте, вместо создания десятков тяжёлых DOM-элементов.

Canvas должен:
- находиться поверх background;
- позволять части foreground beans проходить визуально поверх prize;
- не блокировать touch/click;
- использовать pointer-events: none;
- очищаться/останавливать requestAnimationFrame после завершения celebration.

Не оставлять постоянно работающий animation loop после исчезновения частиц.

--------------------------------------------------
ПРОВЕРКА
--------------------------------------------------

После реализации обязательно проверь реальный flow на телефоне:

«Твій приз чекає»
→ нажимаю «Відкрити приз 🎉»
→ flash
→ появляется крупный prize
→ rarity glow
→ rays
→ ЗАМЕТНЫЙ дождь/взрыв кофейных зёрен
→ примерно через 2–3 секунды дождь заканчивается
→ prize продолжает только очень мягко парить.

Если при reveal видны только 3–5 медленно плавающих зёрен — ЗАДАЧА НЕ ВЫПОЛНЕНА.

Celebration должен быть хорошо заметен, но не перекрывать название приза и основную информацию.
